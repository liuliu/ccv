Partitioned inference probability bounds, 2026-10-03

Retained production change
Remove the redundant [0,127] clamp after rint(P*127) in the existing partitioned
INT8 inference main loop. For finite scores, P=exp2(score-runningMax) is in
[0,1], so this rounding already fits signed INT8. All other conversion,
quantization, normalization, reduction and output operations remain unchanged.
The existing partitioned kernel property carries this source decision through
the cache. There is no new shape threshold, chip-name gate, transpose, scratch
allocation, runtime geometry, backward behavior, or experimental environment
switch in production. The short-KV fallback and FP32-output loops are unchanged.

Why restrict it to the existing algorithm
The isolated global-elision prototype covered 78 shapes: head dimensions
32/64/80/96/128/192/256, tails, static/dynamic lengths, batch/GQA, upcast and
causal controls. Its 386 records include two orders for previous/current on
all 78 and actual MLX on 37 priority cases. All exit zero and paired sampled
CPU errors match. It improves long H3 by about 3%, but some image workloads
regress by about 1-1.7%. Reusing the existing normalized-half partitioned path
captures the consistent gain without adding a model- or size-specific clamp
gate. The broad rows h3-480p-10s and h3-720p-10s are older R29146/R67306 proxies;
rows containing -ui- are exact R31018/R70186 UI sizes. This production report's
application table below uses exact UI sizes for both H3 10-second rows.

Correctness
The global prototype completed 224 randomized/stress executions, with 112
bit-identical full-output pairs. Those cases did not select partitioning.
An additional 56 executions cover R4097/C31018 and R4097/C70186 with D128,
Hq56/Hk7, query/KV tails, and fixed/dynamic lengths: 28 bit-identical pairs.
Inputs include Gaussian Q/K at sigma .25/1/2, key outliers, large V, opposing
V offsets, and sparse near-half-maximum V. All outputs are finite. This is
numerical validation, not rendered image/video quality validation.

The rebuilt production library independently repeats the 28 long-path stress
pairs and adds 32 full-output pairs across selector/dispatch boundaries,
D256, batch/GQA, and causal controls. All 60 pairs are bit-identical to the
immediately preceding implementation. CPU-reference error is unchanged;
existing cancellation stress reaches relative L2 0.0727077, so these results
must not be described as every case having less than 5% error. Existing saved
statistics, aliasing, dynamic cache and CPU-reference integration tests run
in the full MPS suites. No new test merely mirrors the clamp implementation.

Actual application-path comparison
CCV uses NoGrad DynamicGraph, saved LSE, Q/O aliasing and original SHD strides.
All preparation, quantization, attention partitions and merging are included.
Previous/current request INT8 inference; the existing small-D256 fallback still
selects FP16 for Ideogram 512. That row must not be labeled true INT8 execution.
MLX is the checked-out FP16 SDPA implementation with the previously documented
D256 JIT signature fix; it is not a local approximation of MLX. Three warmups,
at least .5 GPU seconds of warmup and seven samples per process. Cases and
implementations run in reversed orders. CPU compilation finishes before GPU
timing; GPU jobs are serial. Values are median of two process medians in ms,
except FLUX.2 512/2048 and Krea 2 2048, which combine four after a confirmation
of noisy initial results. All observations, including MLX 79.95 ms for FLUX.2
2048 and 82.81 ms for Krea 2 2048, are retained in the CSV and summary arrays.

Rejected partition-count extension
An isolated actual-NoGrad experiment forces the existing normalized-half /
per-partition FP32 V-mean algorithm with one, two, four or eight partitions.
Counts round to KV64 tiles; existing bounded query chunks and scratch cap
remain. Eight workloads, six variants including production and actual MLX,
and two reversed orders give 96 records, all exit zero. Images regress even
at one partition; none justify expanding this path. H3 480p gains about 2%
with two/four, but 720p favors eight. This is insufficient evidence for another
selector threshold, particularly because partition count changes rounding.

Rejected short-KV folding
A separate attempt removes the short-C dynamic-K fallback, lets the ordinary
bounded-load loop handle C smaller than its tile, and removes its threadgroup
scratch. It fails the first correctness case R129/C1/D32/B2/Hq8/Hk2: CPU
relative L2 1.23639, full previous-output relative L2 1.15317, max difference
0.361328. The baseline is exact on the sampled CPU check. The driver stops
with exit 4 after two records; no timing or production claim follows. The
fallback is retained. This failure is distinct from the earlier safe isolated
short-branch removal for C known to be at least one complete tile, documented
in inference-short-kv-prototype.txt.
