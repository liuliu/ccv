Inference INT8 GEMM / Float32-store fusion integration, 2026-10-03

Retained: the previous fused-store prototype now runs through the production
MPS GEMM frontend and compiled CNNP inference graphs. The original half rounding
is preserved, and graph arena allocation does not grow. This is an inference
improvement beyond tile tuning; the broader approximately-2x target remains open.

Implementation and reasoning
- Explicit castOutputToFloat is included in both the kernel-source and pipeline
  cache descriptors. INT8 output still rounds into a half fragment before its
  Float32 store. Dimensions and dispatch geometry remain runtime-derived.
- The new try-encode entry point uses the existing register INT8 selector. It
  returns without encoding when unsupported. No new chip-name, per-model, or
  shape tuning gate is added. Normal GEMM selection is unchanged.
- The compiled no-gradient graph recognizes a sole-use GEMM -> Float32 cast.
  It keeps the original symbolic graph, half allocation, edges and cast node.
  A guarded composite executes the widened store when supported; otherwise it
  executes the original half GEMM followed by the cast. The cast node is a NOOP.
- Compiled dependency checks require GEMM to have only the cast successor and
  the cast to have only GEMM as predecessor. Exposed half outputs, half aliases,
  extra consumers, IO flags, control flow, parallel copies and multiviews are
  excluded. Absent tensor symbols are skipped. Graph reinitialization restores
  the original pair before rebinding and then reapplies the guarded composite.
- Heap ranges and offsets are checked against weights and bias. Activation
  overlap is allowed only for a private sole-read intermediate, including a
  contiguous reshape. This INT8 path quantizes the entire activation into
  separate scratch before writing the result. FP16, chunked quantization and
  Hadamard paths use the original pair. Caller-owned/exposed activations do not
  receive the early-overwrite allowance. The original half allocation remains.
- Switching to a gradient graph retains the original commands. Returning to
  no-gradient evaluation can reuse that training graph and stays unfused, as
  required by the existing model lifecycle. No backward optimization is added.

A fallback regression also exposed an existing decoded-weight offset bug:
MPSGraph described a decoded scratch operand using its packed source offset.
The fallback now uses matching decoded buffer, offset and dtype metadata for
the cache key, placeholder and runtime tensor. A nonzero-offset randomized
packed-weight case matches the independent CPU GEMM reference.

Source applicability
Draw Things MiniMaxH3.swift:230-238 reshapes attention output to [1,S,7168],
applies a no-bias output Dense, and immediately converts to Float32.
MiniMaxH3.swift:284-294 does the same conversion after the no-bias FFN-down
projection. These exact dimensions, no-bias setting and private activation
reshape are represented here. The surrounding scalar operations are synthetic
producers/consumers, not complete attention or FFN blocks. No attention transpose
is implemented. The 480p/10s and 720p/10s UI scenarios use S31018 and S70186.
FLUX.2 has the cast adjacency with scaleFactor configured (Flux2.swift:151-164).
Other image graph cases are shape controls, not claims of adjacency or complete
model timing. 768px/2048px image grids use M2304/M16384; Krea/Ideogram include
a stated 256-text-token scenario, giving M2560/M16640. Local Code-specific
non-image workloads retain prior coverage and are not remeasured here.

The newly covered 768px FP16 FFN-down rows expose remaining gaps: FLUX.2 is
about 43% slower than actual MLX, Ideogram about 18%, and Qwen about 6.5%.
Both orders show the FLUX/Ideogram gaps. These paths are unchanged by this
integration. H3 FP16 remains within about 1.1% of MLX in this sweep. Earlier
FP16 parity statements applied to the earlier listed shapes, not all 768px
projections. The FP16 register selector still starts at M4096, excluding these
medium-row cases. The next experiment should compare existing register split
and unsplit paths below that bound with neighboring shapes before changing it.
