INT8 inference: compact attention grids and GEMM remainder loads, 2026-10-03

This checkpoint retains two changes: compact dispatch for appropriate D128
attention grids, and ordinary loads for complete K fragments in the INT8
register-GEMM remainder. Inference is the priority; backward tuning is deferred.
No SHD-to-HSD transpose or other attention layout conversion is introduced.

Attention dispatch
------------------
The existing Morton grid pads both query groups and head count to powers of
two. Compact row-major dispatch emits only live query/head groups, changing
execution order without changing per-query arithmetic. D128 uses it when
KV length >=8192 or padded/live grid size >=1.5 (at least one-third inactive).
The padding calculation uses bulk query groups when bulk/tail splitting is
active. This avoids counting a separately dispatched tail as a full-grid cost.
The long-KV threshold is empirical; these timings do not establish a physical
GPU-cache limit. Compact order also changes access locality, so eliminating
empty groups is not the sole possible cause of its gains.

This applies to FP16-storage, low-precision D128 forward attention without
causal masking, explicit masks, variable lengths or sinks. Backward kernel
ordering remains unchanged. D256 output partitioning already uses compact
order and is unchanged. Selection uses workload geometry, with no added M5
model-name check. The source-generating compact flag participates in kernel
equality/hash and derived pipeline descriptors. Dispatch sizes use the current
runtime descriptor, including query ranges and batch, rather than cached shape.

Evidence: 72 raw pilot executions compare Morton, row-major, head-major and
eight-query-group chunks on nine shapes. All full-output hashes match. That
pilot uses dynamic R/C and must not replace application measurements. A
48-execution application comparison confirms row-major gains against actual
MLX on FLUX, Krea, Qwen and both exact H3 UI rows. A 61-case sweep has 244
executions spanning short queries, rectangular attention, head counts 1-56,
GQA and batch. Unconditional compact order regresses dense short grids (FLUX
last block about 4.3%, Qwen 1024 about 3.1%); the retained policy excludes these.

Two broad-case IDs, qwen21-prefix-text and qwen21-prefix-after-image, are
noncausal geometry controls in that sweep, not real causal-prefix timings.
The archived broad-protocol.json records this distinction. A separate causal
sweep has 56 successful executions on seven actual causal shapes, fixed and
dynamic R/C, with identical full-output hashes. Its prefill losses support
keeping the existing causal order. Another 120 executions examine C8191/8192/
8193, R4096/8192, H8/32/48, and both sides of the padding cutoff, including
dynamic descriptors. Selected cases are generally faster; the weakest are
about 0.7-0.8% slower. No extra head-count or alignment gate is introduced.

GEMM remainder loads
--------------------
The outer reduction remains BK512, with the previously retained unroll-two
main loop. Previously every K32 fragment in the remainder used bounds-checked
loads, including complete fragments. Complete fragments now use ordinary
loads on aligned M/N sides; partial M/N and the final partial K fragment keep
safe loads. H3 Q/up has K5376: its 256-element remainder contains eight complete
fragments. This removes unnecessary checks without changing INT32 products,
accumulation, scales or bias. No new shape gate or reduction-width selector is
added. FP16 source and the imported MLX header remain unchanged.

A 64-execution BK128/256/512/1024 pilot found that BK256 helps H3 Q/up but
regresses some aligned reductions by 4-5%; it is not retained. A separate
64-execution pilot isolates fast remainder loads, remainder unroll-two and
their combination. Fast loads alone are the general choice. The subsequent
83-case sweep compares previous/current/actual MLX in two reversed orders:
498 successful executions, with all 166 previous/current sampled CPU-error
pairs identical. Another 64 executions cover M8193, N2048/2049 and sixteen
K remainders around fragment and reduction boundaries; all 32 full-output
pairs are identical. These boundary checks use 0.2 GPU seconds of warmup;
the main timing protocol below uses 0.5 seconds.

all GPU jobs serial with unrestricted Metal access. Three warmup iterations
and at least 0.5 GPU seconds; nine timed samples for GEMM, seven for attention.

GEMM includes activation quantization; weights are already rowwise INT8.

the other pass; additional passes are included instead of reporting that

Correctness and validation
--------------------------
The production GEMM equivalence sweep has 64 executions / 32 full-output
pairs across eight shapes, fixed/dynamic dimensions, and FP16/INT8 paths.
The attention sweep has 48 executions / 24 full-output pairs across twelve
shapes, fixed/dynamic R/C, GQA, batch, causal controls, both selector boundaries,
partitioned H3 and a D256 control. All 56 pairs are bit-identical and finite.
These checks establish equivalence to the immediately preceding quantized
implementation, not model-quality equivalence to unquantized MLX.

The randomized CPU-reference GEMM integration test now covers sixteen shapes,
adding K4127/4128/4129 with partial M/N and actual H3 K5376. The attention
query-range/compact-grid test now covers 26 shapes in both fixed/dynamic modes:
52 scenarios with GQA/batch, sampled CPU attention and saved log2 LSE, all
output finiteness, and same-cache transitions across both policy thresholds.
The existing Vx1000 stress scenario is preserved. Both focused tests pass.
Full MPSBLAS: 298/298, exit zero. Full MPSDNN: 126/126, exit zero.
git diff --check passes. No changes have been staged or committed.

The earlier D256 checkpoint switched a requested-INT8 region from FP16
fallback to actual INT8. It does not share this checkpoint's bit-equivalence
claim. Its measured quantization errors and adversarial cancellation behavior
remain documented in inference-output-split.txt; rendered quality is untested.

Remaining inference gaps
------------------------
The broad approximately-2x goal remains open. H3 attention is now around
1.88x / 2.0x MLX, H3 Q/up around 1.79-1.85x and FFN-down around 2.03-2.11x.
Large D128 image attention remains around 1.67-1.74x; D256 Ideogram 2048 about
1.81x. Small image attention has less headroom and several ratios near
1.3-1.6x. Earlier FP16 production comparisons remain within 1.6% for GEMM and
1.3% for attention, or faster; this checkpoint does not change those shaders.
Further inference work should examine per-tile state and fragment/control
costs without assuming that another tile or hardware-name gate will solve it.
Backward optimization remains deferred; actual MLX VJP comparisons remain in
priority-report.txt.

Artifacts with prefix inference-grid-tail retain the production CSVs, combined
medians, exact manifests, full-output hashes, complete validation results,
prototype sweeps, source snapshots, integration diff, logs and SHA256 provenance.
Prototype environment controls exist only in scratch binaries.
