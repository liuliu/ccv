Method
Three variants alternate in one process with separate MFA contexts and the
same inputs, buffers and command queue. Submission order is 0,1,2,2,1,0,
rotating the variant labels each block. Timings include Q/K/V preparation.
Normally 24 samples per variant after at least six warmup submissions and
0.3 aggregate GPU seconds; confirmations use 96 samples. Thermal state is
checked before and after each submission. Pause 100 ms after each six calls
and 15 seconds between cases. No samples are removed from accepted runs.
The harness copies the three loop generators verbatim. All 2,304 generated
source comparisons match their standalone generators exactly.

Short-workload timing control
For dense BF16, the first single-encode comparison reports gated +5.1%; a
96-sample confirmation reports -12.6%. Uniform and gated emit identical
shaders here, yet their medians differ by 4-9%. These runs are retained.
Periodic latency spikes and differences between identical shaders prevent
a reliable 2% conclusion from the single-encode samples for this shape.

H3 480p/10s: R=C31018/D128/B1/H32/H32, fixed lengths, FP16. Five-second
cooling pauses after every submission, including warmup; one encode per
command buffer. Original 1009.414 ms, uniform 963.160 ms, gated 964.476 ms
(-4.5%). Only two measured samples per variant: useful as a final long-shape
check, not a precise regression bound. The S70186 case was not run on iPad.

Correctness
Fourteen dedicated cases pass with all three variants: causal R>C empty
rows for D64/128/192/256 with FP16 and FP32; short key lengths 1 and 29;
D192 sinks and varlen; packed masks split at token 100, both noncausal
D128 and causal D192. These short runs are for correctness, not timing.
Every performance run also compares the full outputs between variants and
checks sampled outputs against a CPU reference. LSE buffers are byte-identical
between all three variants. Small output rounding differences from FMA remain
within the checks. No backward code is changed by this work.

All 42 launches passed (28 timing comparisons and 14 dedicated correctness
cases). Every thermal check remained nominal (state 0); no thermal retries
or rejected runs. Production changes remain limited to the forward output
update and its source-generation gate; the test switches are scratch-only.
