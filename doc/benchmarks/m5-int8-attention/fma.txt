Dynamic causal investigation and final fallback

The per-iteration cS_0 zeroing before QK (cP_0 aliases cS_0) is unchanged.
Causal cO initialization is also unchanged. The arithmetic/dataflow difference
is that the original consumes correction to rescale cO before exponentiation,
row-sum reduction, probability quantization and PV; the fused update needs it
after each PV result. This establishes the changed dependency/lifetime, but is
not proof of a particular register-allocation or instruction-scheduling cause.

Controlled shader experiments did not recover the uniform change's regression:
- Explicit separate multiply/add at the late update: +23.8% vs original.
- Fuse the PV product instead, or leave the expression to contraction: +17.6-18.0%.
- Map correction into output layout once, early or late: +7.6-7.9%.
- Move V-scale calculation later: +7.4%; move L accumulation later: +22.8%.
- Change runtime-bound uniform annotations: +7.2-7.9%.
- Set the pipeline thread limit to the actual group size: +7.1%.
- Retain early scaling for only some output blocks: +5.7-10.1%.
- Merge causal exponent branches: +6.3%; it also changes one FP16 LSE entry by
  one representable step. Applying that diagnostic to the original costs 25.1%.
These are diagnostic-only changes. None is included in the final candidate.

The uniform regression repeats across C4096/8192/16384, FP16/FP32/BF16,
ordinary H8/H8 and grouped H16/H4 or H32/H8 attention. Row tails, masks and
other tested head dimensions behave differently: R4097 is 23.6% faster,
masked attention 10.1% faster, and D112/144/160/176/192 improve 13.5-25.7%.
A column tail alone still regresses 2.7-2.9%; it is not an exemption.

The final candidate retains early rescaling when all conditions hold:
  !tileOutput && isCausal && !masked && loadR && loadC && !hasRRemainder
There is no head-dimension-specific exception. Existing tiled outputs retain
their original FMA update. All other forward paths use the fused output update. These properties already
belong to the kernel descriptor/cache key; no new descriptor field, user option,
runtime shader branch, precision change or dispatch choice is introduced.

This fallback is deliberately conservative. In this shader class, the uniform
change improved D112/144/160/176/192 by 13.5-25.7%, and D128 H16/H16 or H32/H32
by 13.0-15.7%. The final rule gives up those new gains. It avoids empirical
exceptions for particular head dimensions or KV-head counts and preserves the
original performance throughout the class. Dense, masked, variable-length,
query-row-tail, and fixed-length gains remain.

Final paired checks use 128 samples per arm, the same ABBA/BAAB protocol and
thermal-state checks. Original and final outputs/LSE are bit-identical for the
gated cases. Remaining FMA paths keep the expected tiny rounding differences.

Follow-up: isolating hasRRemainder (2026-10-06)

The R4096 -> R4097 comparison also crosses a padded-grid boundary. Controls
on Max remove that confound: at R4080 and R4081, the grid size is unchanged,
yet uniform FMA goes from +7.1% to -24.3%. R4112 is aligned but uses the larger
grid and again regresses (+7.0%). All use C8192/D128/Hq16/Hkv4, runtime R/C.

A stronger diagnostic keeps R4096, inputs, quantization, dispatch, and loop
initialization identical and changes only the forward runtime constant:
  R_remainder = 0u  ->  R_remainder = uint(R) % 16u
The actual value remains zero. This retains the runtime output/LSE tail branch
instead of allowing it to be removed at compile time. Original output and LSE
remain bit-identical. Max GPU ms:
  Compile-time zero: original 2.950, uniform FMA approximately 3.18.
  Runtime remainder: original 4.561, uniform FMA 3.494 (-23.4%, paired).
Thus the row-tail predicate affects compiler output, not merely workload size
or grid padding. The precise instruction-scheduling/register-allocation change
is still unobserved. The diagnostic is not a production change and is not a
fix: retaining the runtime remainder slows both versions versus their normal
aligned forms. The cP/cS zeroing inside the KV loop is unchanged throughout.
